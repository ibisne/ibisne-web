§ 00.CRM + LIVING CODING — iBisne MVP 1 · v0.3

Mi día.
Mi proyecto.
Paso a paso.

v0.3 expande a la visión completa: el CRM ahora es también sistema operativo de ejecución. Cada proyecto vive como secuencia de pasos bloqueados según el playbook (Bio-link, Landing, Sitio completo, Ecom, App, SaaS, AI, Web3 · 10+ templates). Un Jr Coder ve "Mi proyecto" con el paso actual destacado, recursos inline, checklist, y siempre sabe el siguiente movimiento. KAM + Arquitecto declaran tech stack apropiado al inicio (HTML+CSS para bio-link, Next + Sanity para sitio completo, React Native + Expo para app híbrida).
